Section 05

Hooks

CLAUDE.md는 무시될 수 있다. Hooks는 반드시 실행된다.

CLAUDE.md vs Hooks -- 핵심 구분

CLAUDE.md = "안내문" (advisory)

  • Claude가 무시할 수 있음
  • ".env 파일 수정 금지"
  • "Prettier로 포맷팅"

Hooks = "자동문" (enforced)

  • 100% 실행 보장
  • .env 편집 시도 → 자동 차단
  • 파일 저장 → 자동 Prettier

"Claude가 이걸 무시하면 큰일 나는가?" → 예: Hooks | 아니오: CLAUDE.md

Hook이란 무엇인가

  • Claude가 특정 행동을 할 때 자동으로 실행되는 스크립트
  • 실행 주체: Claude가 아니라 하네스(시스템)가 실행
  • "사람 개입 없이 매번 자동으로 실행되는 규칙"
Claude의 동작 Hook이 자동 개입 --------------------------------------------- 파일 수정하려 함 → "잠깐, 이 파일은 안 돼!" (차단) 파일 수정 완료 → "자동 포매팅 돌려놓을게" (자동화) 세션 시작 → "현재 상황 미리 알려줄게" (컨텍스트)

CI/CD에서 린트가 실패하면 PR이 머지 안 되는 것처럼 -- 선택의 여지가 없는 규칙

Hook 라이프사이클 -- 5가지 실행 시점

실무 90%는 PreToolUse, PostToolUse, SessionStart 3가지로 해결

주요 Hook 이벤트

Hook시점대표 용도
PreToolUse도구 실행 전.env 편집 차단, 위험 명령 차단
PostToolUse도구 실행 후자동 Prettier, 자동 린트
SessionStart세션 시작 시git 상태 주입, 환경 정보 로딩
UserPromptSubmit프롬프트 제출 직후컨텍스트 자동 주입
StopClaude 응답 완료 시결과 로깅, 자동 정리
Notification알림 발생 시Slack/Discord 연동

Hook 작성법 -- settings.json 구조

// .claude/settings.json { "hooks": { "PreToolUse": [ { "matcher": "Edit|Write", "hooks": [ { "type": "command", "command": "스크립트 또는 명령어", "timeout": 10 } ] } ] } }
키설명예시
matcher어떤 도구에 반응할지"Edit|Write"
typeHook 유형"command"
command실행할 명령셸 스크립트
timeout제한 시간 (초)10, 15

참고: 실전 Hooks 설정 예시 (모든 Hook 타입을 커버하는 완전한 settings.json)

PreToolUse 예시 -- .env 편집 차단

1 Claude가 Edit/Write 도구를 쓰려고 함 | v 2 Hook이 stdin으로 파일 경로를 받음 {"tool_input": {"file_path": ".env"}} | v 3 파일명이 .env면 → "deny" 출력 → 차단됨 그 외 파일이면 → 아무것도 안 함 → 허용됨

CLAUDE.md에 ".env 수정 금지"라고 써도 Claude가 무시할 수 있지만, Hook으로 차단하면 물리적으로 불가능

PostToolUse 예시 -- 자동 포매팅

// PostToolUse Hook: 파일 수정 후 자동 Prettier { "matcher": "Write|Edit", "hooks": [{ "type": "command", "command": "FILE=$(...); npx prettier --write \"$FILE\"", "timeout": 15 }] }
  • Claude가 파일을 수정할 때마다 → 자동으로 Prettier 실행
  • "포맷팅 해줘"라고 말할 필요 없음
  • 팀 코드 스타일이 항상 일관됨

SessionStart Hook -- 동적 컨텍스트 로딩

// SessionStart: 세션 시작 시 git 상태 자동 주입 { "hooks": [{ "type": "command", "command": "echo '## Current Context'; \ git branch --show-current; \ git log --oneline -5; \ git status --short", "timeout": 10 }] }
  • 새 세션 시작 시 Claude가 자동으로 현재 상황을 인지
  • "지금 어떤 브랜치야?" 질문 불필요
  • CLAUDE.md는 정적, SessionStart Hook은 동적 (실시간 정보)

실습 Part 1 -- .env 편집 차단

1 Hook 없는 상태에서 .env 수정 요청

.env 파일에 NEXT_PUBLIC_API_URL=http://localhost:4000을 추가해줘.

예상 결과: Claude가 .env 파일을 수정함 (위험!)

2 .claude/settings.json에 보안 Hook 추가

3 동일 요청 재시도 → 차단됨!

같은 요청인데 Hook 추가 후엔 차단 -- "안내문 vs 자동문"

실습 -- PreToolUse Hook 코드

// .claude/settings.json { "hooks": { "PreToolUse": [{ "matcher": "Edit|Write", "hooks": [{ "type": "command", "command": "FILE=$(jq -r '.tool_input.file_path' < /dev/stdin); \ if echo \"$FILE\" | grep -q '\\.env'; then \ echo '{\"hookSpecificOutput\":{...\"deny\"...}}'; \ fi", "timeout": 10 }] }] } }

파일 경로에 .env가 포함되면 → deny 응답으로 차단

실습 Part 2 -- 자동 포매팅 Hook

1 settings.json에 PostToolUse Hook 추가

"PostToolUse": [{ "matcher": "Write|Edit", "hooks": [{ "type": "command", "command": "FILE=$(...); \ if echo \"$FILE\" | grep -qE '\\.(ts|tsx|js|jsx)$'; then \ npx prettier --write \"$FILE\"; \ fi", "timeout": 15 }] }]

2 코드 수정 요청 → 자동 포매팅 확인

Claude가 코드를 수정한 직후, Prettier가 자동으로 실행됨

실습 Part 3 -- SessionStart 동적 컨텍스트

1 settings.json에 SessionStart Hook 추가

"SessionStart": [{ "hooks": [{ "type": "command", "command": "echo '## Current Context'; \ echo \"Branch: $(git branch --show-current)\"; \ git log --oneline -5; \ git status --short", "timeout": 10 }] }]

2 /clear 후 "지금 프로젝트 상황이 어때?"

3 Claude가 추가 명령 없이 바로 현재 상태를 알고 있음

완성된 settings.json

{ "hooks": { "SessionStart": [{ "hooks": [{ "type": "command", "command": "git branch/log/status 주입" }] }], "PreToolUse": [{ "matcher": "Edit|Write", "hooks": [{ "type": "command", "command": ".env 파일이면 deny" }] }], "PostToolUse": [{ "matcher": "Write|Edit", "hooks": [{ "type": "command", "command": "npx prettier --write" }] }] } }

SessionStart = 컨텍스트 준비 | PreToolUse = 위험 차단 | PostToolUse = 자동화

핵심 정리 -- Hook 3종 세트

PreToolUse = "이건 차단해라" (방어)

.env 보호, 위험 명령 차단

PostToolUse = "알아서 해라" (자동화)

자동 Prettier, 자동 린트, 자동 테스트

SessionStart = "미리 준비해라" (컨텍스트)

git 상태, 환경 정보, 최근 이슈

"CLAUDE.md는 무시될 수 있다. Hooks는 반드시 실행된다."
