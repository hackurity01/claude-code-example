Claude Code Overview

Claude Code가 무엇이고 왜 강력한지 눈으로 확인한다. 전체 기능 지도를 머릿속에 갖는다.

라이브 데모 -- "3분 버그 수정"

TaskFlow 앱에서 "최신순 정렬"이 역순으로 동작하는 버그를 Claude Code에게 수정 요청

bash git clone https://github.com/hackurity01/claude-code-example.git cd claude-code-example git checkout instructor/demo npm install claude

src/lib/utils.ts의 sortByDate 함수에서 최신순 정렬이 역순으로 동작해.
문자열 비교 대신 Date 객체로 비교하도록 수정하고, 테스트를 돌려줘.

데모 해설 -- Claude가 한 일

단계Claude의 동작사람이 한 일
1프로젝트 구조 파악프롬프트 입력
2src/lib/utils.ts 찾아서 읽기(없음)

핵심: 파일 탐색 → 분석 → 수정 → 검증을 자율적으로 수행

AI 코딩 도구의 3세대 진화

1세대: 자동완성 (Copilot, 2021~) → 커서 위치에서 다음 코드를 "예측" → 한계: 파일 하나만 봄, 실행 불가 2세대: 채팅 (ChatGPT, 2022~) → 코드를 복사해서 물어보면 답변 → 한계: 프로젝트 전체를 모름, 직접 수정 불가 3세대: 에이전트 (Claude Code, 2025~) → 코드베이스 전체를 읽고 이해 → 파일을 직접 편집하고 명령을 실행 → 테스트, 커밋, PR까지 자동화

비유로 기억하기

  • 1세대 = 받아쓰기 도우미 (다음 단어 예측)
  • 2세대 = 옆자리 선배 (물어보면 답해줌)
  • 3세대 = 신입 개발자 (알아서 읽고, 수정, 테스트)

토큰과 컨텍스트 -- 빠르게 이해하기

  • 토큰 = Claude가 처리하는 정보의 단위 (대략 단어 ~ 음절 크기. 같은 내용이라도 한국어는 영어보다 토큰을 더 많이 소모)
  • 컨텍스트 윈도우 = 한 번에 처리할 수 있는 토큰의 총량
  • 비용 = 입력 토큰 + 출력 토큰으로 계산
모델별 컨텍스트 크기: Opus 4.7 / 4.6 → 1M 토큰 (A4 약 1,500장) Sonnet 4.6 → 200K 토큰 (A4 약 300장) Haiku 4.5 → 200K 토큰 (고속 처리)

왜 중요한가: 토큰이 많이 차면 → Claude가 "까먹기" 시작. 토큰 관리 = Claude를 잘 쓰는 핵심 스킬 (섹션 2에서 자세히)
