RTK -- Hook 기반 토큰 절약 도구

항목내용
한줄 요약Shell 명령 출력을 자동 압축하여 토큰 60-90% 절약
작동 방식Hook이 모든 shell 명령을 RTK 경유시켜 출력 압축
설치 후 할 일없음. 자동으로 동작
git status 155줄 → 3줄 (98% 절약) npm list 240줄 → 12줄 (95% 절약) git log 100줄 → 15줄 (85% 절약) ------------------------------- 30분 세션 평균: 토큰 70% 절약
curl -fsSL https://rtk-ai.app/install.sh | bash rtk init -g # Claude Code Hook 자동 설정

Context7 -- 최신 문서 실시간 조회

Upstash가 만든 MCP 서버. 최신 버전별 라이브러리 문서와 코드 예제를 소스에서 직접 가져와 프롬프트에 주입

Context7이 해결하는 문제설명
구버전 코드 예제학습 데이터 기준 연도의 코드를 생성
환각 API실제로 존재하지 않는 함수/메서드를 만들어냄
버전 불일치구버전 패키지에 맞는 답변을 제공
작동 방식 (2단계): 1. resolve-library-id "next.js" → /vercel/next.js 2. query-docs /vercel/next.js + "middleware" → 최신 문서

설치:

# 권장 (인증+설정 자동) npx ctx7 setup --claude # 또는 수동 MCP 등록 claude mcp add context7 -- \ npx -y @upstash/context7-mcp@latest

사용법:

# 키워드 추가 Next.js 미들웨어 설정해줘. use context7 # 라이브러리 ID 지정 use library /supabase/supabase

공식 GitHub: github.com/upstash/context7

실습 Part 3 -- Superpowers TDD 체험

1 Superpowers 설치 (step/04-hooks 브랜치에서 계속)

/plugin marketplace add obra/superpowers /plugin install superpowers@superpowers # /clear 로 새 세션

2 TDD로 기능 구현 요청

TaskFlow에 changePriority 함수를 TDD로 구현해줘. src/lib/utils.ts에 추가해. - Task 객체와 새 Priority를 받아서 priority가 변경된 새 Task를 반환 - 원본 Task는 변경하지 않을 것 (불변성)

3 Red → Green → Refactor 사이클 관찰

실습 -- TDD 흐름 관찰

Superpowers TDD 사이클 (실습에서 확인) [RED] __tests__/lib/utils.test.ts에 changePriority 테스트 추가 → npm test 실행 → 실패 X (함수가 아직 없으니까 당연히 실패) [GREEN] src/lib/utils.ts에 changePriority 최소 구현 → npm test 실행 → 통과 V (테스트를 통과시키는 최소한의 코드) [REFACTOR] 코드 품질 개선 → npm test 실행 → 여전히 통과 V

확인 포인트:

  • 테스트가 먼저 작성되었는가?
  • 구현 전에 테스트가 실패하는 것을 확인했는가?
  • 리팩토링 후에도 테스트가 여전히 통과하는가?
