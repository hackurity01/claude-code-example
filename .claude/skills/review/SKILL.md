# Code Review

대상 파일을 읽고 다음 관점에서 리뷰하라:

1. **버그 가능성** — 로직 오류, 누락된 처리, 타입 불일치
2. **타입 안전성** — CLAUDE.md 규칙 기반 (any 금지, strict mode)
3. **에러 처리 누락** — try/catch 없는 비동기 호출, 미처리 에러
4. **테스트 커버리지** — 대상 파일에 대한 테스트 존재 여부
